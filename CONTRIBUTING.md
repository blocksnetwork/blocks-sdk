# Contributing to Blocks Network SDK

Thank you for your interest in contributing. This document will be
expanded with detailed guidelines before the first public release.

## Getting Started

1. Fork and clone the repository.
2. Run `make setup` to install all dependencies.
3. Create a feature branch from `main`.
4. Make your changes with tests.
5. Run `make test` and `make lint` to verify.
6. Open a pull request.

## Code of Conduct

All contributors must follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting Issues

Use GitHub Issues for bug reports and feature requests.
